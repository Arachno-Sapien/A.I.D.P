## 1. Goal

Type a message and get a streamed reply from one OpenAI-compatible provider, with Stop, Markdown, and code blocks you can copy. This is the model layer that the coding workspace (M3) and agent tools (M4) build on.

Done means (design doc, "Milestones"):

- [ ] Type a message and get a streamed reply from one OpenAI-compatible provider
- [ ] Stop cancels a reply midway
- [ ] Code blocks render with a copy button
- [ ] Adapter tests cover success, 401, 429, and a dropped stream

## 2. Decisions made while planning

- **reqwest uses `native-tls`** (Windows SChannel) instead of 0.13's default rustls with aws-lc-rs, which needs CMake and NASM on Windows. Decision record 0006 is written in Task 2.
- **The `ModelProvider` trait has only `stream_chat` in M1.** `list_models` and `test_connection` arrive in M2 with the Models page that uses them.
- **The adapter sends only `Delta`.** The `send_message` command sends the single `Done` or `Error`.
- **The design's catch-all `ProviderError` kind is the `Provider` variant,** to avoid `ProviderError::ProviderError`.
- **No `stream_options` in requests.** Usage is reported only when the provider sends it.
- **The M1 key file is `config.local.json` in the app config folder,** outside the repo. M2 replaces it with the keychain.
- **A small in-app navigation guard** keeps the window on the app when a reply contains a link (security rule 5).
- **M1 chats live in memory only.** Long-list virtualization comes with history in M5.
