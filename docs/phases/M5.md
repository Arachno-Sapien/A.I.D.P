## 1. Goal

Local Ollama models work like cloud models in Chat and the workspace: the app detects Ollama, starts it, downloads, deletes and unloads models. Chats and each folder's AI panel conversation survive a restart, and every reply records its model. A Settings screen sets the default model, the theme, and how long local models stay loaded (design doc, "Local models (Ollama)", "Data model", "Screens and user flows").

Done means (design doc, "Milestones"):

- [ ] App detects Ollama and starts it if stopped
- [ ] Downloaded models appear in the picker and work in Chat and the workspace
- [ ] Download with progress and cancel; delete with confirmation; Free memory unloads the model
- [ ] Chats survive an app restart, and each message records its model
- [ ] Settings for default model, theme, and keep\_alive work

## 2. Decisions made while planning

The full list is in the plan, under "Decided in this plan". The ones that shape the code most:

- **Ollama is one built-in connection** (kind `ollama`, fixed `http://127.0.0.1:11434`, no key). Its downloaded models are synced into `models`, so the picker, the default model and each message's model work the same for every provider.
- **A new `ollama_chat.rs` adapter** uses `/api/chat` with tools, `num_ctx` and `keep_alive`, behind the same trait.
- **History:** two tables (`conversations`, `messages`); the UI decides when to save and only Rust writes SQLite. Each reply stores its model reference and name.
- **Small context windows:** what the panel attaches and what one tool result returns are capped at 2 characters per context token.
- **The theme** swaps Tailwind's neutral palette through CSS variables.
- **Found while planning:** the model picker splits its key on every `:`, which breaks Ollama names like `qwen2.5-coder:1.5b`; Task 8 fixes it.
- **D1 to D5, approved with the defaults:**
  - D1: Ollama not installed → a link to its download page (the open question in AGENTS.md section 14).
  - D2: Start runs `ollama serve` and leaves it running after A.I.D.P quits.
  - D3: a Chat sidebar of conversations, one conversation per workspace folder; no export.
  - D4: Dark, Light and System themes by palette swap.
  - D5: `num_ctx` 8,192, keep-alive choices, the text budget, suggested downloads with sizes.
