## 1. Goal

## 2. Decisions made while planning

- **Keychain behind a trait.** `SecretStore` with `Keychain` (keyring 4.2, real) and `MemoryStore` (tests). Tests never touch the real Credential Manager. keyring 4's default feature picks the OS store per target, so no platform features are needed.
- **Connection rows in SQLite, keys in the keychain.** Entry service `com.aidp.desktop`, user `connection-{id}`. SQLite keeps the last 4 characters of the key, and only when the key has at least 12 characters.
- **`u32` ids and timestamps**, because specta rejects 64-bit integers.
- **Database** `{app_data_dir}/aidp.db` with `connections` and `models` only; migrations via `PRAGMA user_version`, no extra crate. Capability columns and the history tables come in later migrations.
- **A failed test saves nothing.** `add_connection` lists the provider's models first, then writes the row, then the keychain entry, and rolls the row back if the keychain fails.
- **Anthropic over raw HTTP** (Rust has no official SDK): `anthropic-version: 2026-10-21`, `max_tokens` 8192, system messages moved to the top-level `system` field, `refusal` stop reason handled.
- **Shared gateway code.** The status mapping and the SSE read loop move from the OpenAI-compatible adapter into `gateway/http.rs`, so both adapters share them.
- **One shared `reqwest::Client`** in app state with a 15 s timeout on list and test requests and 10 s connect timeout.
- **`remark-gfm` for tables** included (decision D1).
- **The Models page is the connection settings surface**; M5's Settings links to it.
- **Tasks 6 to 8 shared one commit**, ensuring the tree was never red during the IPC and UI refactor.

## 3. Built, changes from the plan, what's left

### What was built

1. **Shared Gateway Helpers (`src-tauri/src/gateway/`):**
   - Added `ModelInfo` and extended `ModelProvider` trait with `list_models` and `test_connection`.
   - Shared HTTP line-buffering and SSE parser in `gateway/http.rs`.
   - Shared transport classification and base URL validation in `gateway/url.rs`.
2. **Anthropic Adapter & Factory (`src-tauri/src/gateway/anthropic.rs`, `src-tauri/src/gateway/mod.rs`):**
   - Implemented `Anthropic` adapter with `x-api-key` header marked sensitive.
   - Provider factory constructing either `OpenAiCompat` or `Anthropic` adapters.
3. **Keychain Wrapper (`src-tauri/src/secrets.rs`):**
   - `SecretStore` trait with `Keychain` (OS Credential Manager) and `MemoryStore` (for deterministic unit tests).
4. **SQLite Persistence (`src-tauri/src/db/`):**
   - Database connection management with `PRAGMA user_version` migrations.
   - `connections` and `models` tables with `ON DELETE CASCADE` foreign keys.
5. **Connections Service (`src-tauri/src/connections.rs`):**
   - Orchestration service `Services` managing connection lifecycle: validation, test-then-add with automatic rollback, key replacement, deletion, and streaming chat using stored credentials.
6. **Thin Commands & App State Wiring (`src-tauri/src/commands/`, `src-tauri/src/lib.rs`):**
   - 9 connection/model commands in `src-tauri/src/commands/connections.rs`.
   - Rewrote `send_message` in `chat.rs` using `connection_id` and `model_id`.
   - Deleted legacy `config.rs`.
   - App state managed in `lib.rs` with shared `reqwest::Client`.
7. **Frontend Data Layer & UI Components (`src/features/models/`, `src/features/chat/`, `src/App.tsx`):**
   - Provider presets in `providers.ts`.
   - Normalized error formatting in `appErrorText.ts`.
   - Zustand model store in `models/store.ts`.
   - `AddConnectionDialog.tsx` with 2-step setup.
   - `ChooseModels.tsx` with text search and 200-model cap.
   - `ModelsScreen.tsx` with connection cards, key masking, inline delete confirmation, and rekeying.
   - `ChatScreen.tsx` with connection-grouped model selector and first-run empty states.
   - `App.tsx` with top navigation bar.
8. **GFM Tables in Markdown (`src/features/chat/Markdown.tsx`, `src/App.css`):**
   - Integrated `remark-gfm@4` for tables, strikethrough, and task lists.
9. **Documentation:**
   - `docs/security.md`, Decision Record 0007 (`docs/decisions/0007-connections-storage.md`), and updated `docs/setup.md`.

### Changes from the plan

- **Test placement:** `map_error_type_table` and `factory_builds_the_right_adapter` placed in `tests/anthropic.rs`.
- **`SecretString` comparisons:** Compared unwrapped errors or `expose_secret()` in test assertions since `SecretString` intentionally does not implement `PartialEq`.
- **Whitespace trimming:** Trimming pasted API keys before testing and saving to avoid whitespace causing `HeaderValue` parsing errors.
- **`ChooseModels` initial selection:** Added `initialSelected?: string[]` prop to `ChooseModelsProps`, defaulting to empty set so that in `AddConnectionDialog` models are not pre-selected by default and ticking one model saves only that model.
- **JSDOM test setup:** Added explicit `cleanup()` in `afterEach` for component test files and used defensive optional chaining on `scrollIntoView`.
