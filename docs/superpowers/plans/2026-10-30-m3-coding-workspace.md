> **Status: approved by the human on 2026-10-30** with the defaults for D1 (dialog plugin from Rust only), D2 (recent folders now) and D3 (Apply needs a saved file). Execute from Task 1. After Task 4, stop for a review before starting Task 5.

Steps use checkbox (`- [ ]`) syntax. **Do not tick any milestone box, in any file, until the human confirms the live check in Task 12. Do not push; the human decides.**

**Goal:** A Workspace screen where the user opens a folder, browses a `.gitignore`-aware file tree, edits files in CodeMirror 6 tabs, asks a model about the open file or selection in an AI panel, and applies a code block from the reply through a diff that reaches the disk only on Accept.

**Architecture:** Rust owns the folder. `src-tauri/src/workspace/` resolves every path the UI sends (workspace-relative, `/`-separated) against the canonical root and refuses anything that lands outside it; it lists folders with the `ignore` crate, reads and writes text files (line endings, BOM and a version token preserved), and flags secret-looking files. The folder itself comes from a native dialog opened from Rust, so the UI never hands an absolute path to the OS. The frontend keeps editor buffers in CodeMirror states, builds the AI context message itself (it has the live buffer), streams through the same `send_message` command as Chat on a separate `ChatSurface`, and turns a code block into a proposal shown with `@codemirror/merge`.

**Tech stack:** what M2 has, plus Rust `ignore` 0.4 and `tauri-plugin-dialog` 2.8 (D1); JS `codemirror` 6 with `@codemirror/state`, `@codemirror/view`, `@codemirror/language`, `@codemirror/language-data`, `@codemirror/merge`, `@codemirror/theme-one-dark`, and `@tanstack/react-virtual` 3.

**Spec:** [docs/design.md](../../design.md): "Coding workspace", "Workspace and tool security", "Screens and user flows" (Workspace, "Flow: work on code with AI"), "Data model", "Milestones -> M3". Rules: [AGENTS.md](../../../AGENTS.md) sections 4, 6 (workspace list) and 7. M2 follow-ups: the review on 2026-10-30 (Task 1).

## Global Constraints

- **Workflow:** the gate (AGENTS.md section 8) before every commit; one commit per task; update `.ai/memory/progress.md` after each; every new dependency gets a one-line reason in its commit body.
- **Rust:**
  - No `unwrap()` or `expect()` outside tests (clippy enforces it).
  - Never hold a `std::sync::Mutex` guard across an `.await`. Copy the root `PathBuf` out of the lock, drop it, then await.
  - File and folder work runs inside `tauri::async_runtime::spawn_blocking` from `async` commands, so a slow disk never freezes the window.
- **Workspace security (AGENTS.md section 6, workspace list, as it applies to M3):**
  - **One folder.** Every path the UI sends is relative to the open folder, with `/` separators. Rust resolves it, following symlinks, and refuses anything that lands outside, including `..`, absolute paths, drive prefixes and `:`. The only absolute paths that cross the IPC are the folder's own display path and the recent-folders list, and `open_recent` accepts a path only if it is in that stored list.
  - **Files go through Rust.** The Tauri fs and shell plugins stay off. The dialog plugin is registered for Rust use only: no `dialog:` permission is added, so JavaScript cannot call it. `src-tauri/capabilities/` does not change.
  - **Edits are proposals.** Apply never writes. Only Accept calls `write_file`, with exactly the text shown in the diff.
  - **Secrets stay out of prompts.** A file whose name looks like a secret (`.env*`, `*.pem`, `*.key`, `id_rsa*`, `id_ed25519*`) can be opened by the user, but its file chip starts removed; it is sent only if the user adds it by hand.
  - **Warn without git.** A banner when the folder is not in a git repository, and a confirmation before the first Accept in that folder.
- **Paths on Windows:** `std::fs::canonicalize` returns verbatim paths (`\\?\C:\...`), in which `/` is **not** a separator. Never `root.join(rel)` with a UI string: push each `Path::new(rel).components()` item onto the root. Strip the `\\?\` prefix only for display.
- **64-bit integers cannot cross the IPC:** sizes are `u32`; the file version token is a `String`.
- **`src/lib/bindings.ts`** is regenerated by `cargo test`, committed, never edited by hand.
- **Component tests** register `afterEach(cleanup)` (Vitest `globals` is false; see known-issues). CodeMirror is created only in `src/features/workspace/cm.ts`; component tests `vi.mock("./cm")`, and logic lives in plain modules that tests import directly.
- **Verified against sources on 2026-10-30** (do not re-research; if the compiler disagrees, trust the compiler):
  - `tauri-plugin-dialog` 2.8.4 is the newest release for Tauri 2 (3.0 is an alpha for Tauri 3; do not use it). Register with `.plugin(tauri_plugin_dialog::init())`. From an `async` command: `use tauri_plugin_dialog::DialogExt; app.dialog().file().blocking_pick_folder()` returns `Option<FilePath>` (`None` when the user cancels); the plugin's own docs show exactly this inside an async command. `FilePath` is re-exported from `tauri-plugin-fs`; convert with `into_path()` (returns a `Result<PathBuf>`). Depending on `tauri-plugin-fs` as a crate does not register the fs plugin.
  - `ignore` 0.4.34 `WalkBuilder`: `max_depth`, `hidden` (default true: skips dotfiles), `parents` (default true: reads `.gitignore` from parent folders), `require_git` (default true: `.gitignore` rules apply only inside a git repository, and parent `.gitignore` files above the repo root are not read, which matches git), `filter_entry`, `follow_links` (default false).
  - npm, newest on 2026-10-30: `codemirror` 6.0.2, `@codemirror/state` 6.7.6, `@codemirror/view` 6.43.15, `@codemirror/language` 6.13.1, `@codemirror/language-data` 6.5.2, `@codemirror/merge` 6.12.3, `@codemirror/theme-one-dark` 6.1.3, `@tanstack/react-virtual` 3.14.24. Install with `^` ranges on these majors.
  - The release CSP is `default-src 'self' ipc: http://ipc.localhost` (no inline styles); dev adds `style-src 'unsafe-inline'`.

  - CodeMirror's runtime styles work under the release CSP, because WebView2 supports constructable stylesheets and CodeMirror sets element styles through the CSSOM. Task 7 step 3 checks it in a release build before anything else is built on top.

## Decided in this plan (record them in docs/phases/M3.md)

- **Workspace-relative paths only.** The UI and Rust exchange paths like `src/app.ts`. `..` is refused even when the result would stay inside (`src/../a.ts`); the simple rule beats normalising.
- **Open existing files only.** Saving and Accept write files that already exist. Creating, renaming and deleting files is M4 (`create_file`) or later.
- **Text files up to 2 MB, UTF-8 only.** Larger files: `TooLarge`; a NUL byte in the first 8,000 bytes or invalid UTF-8: `NotText`.
- **Line endings and BOM round-trip.** Rust normalises to `\n` on read and reports the file's line ending (CRLF when CRLF lines outnumber LF-only lines) and BOM; `write_file` converts back. A file with mixed endings is written with its dominant one.
- **Version token** = modified time in nanoseconds plus size, as a string. `write_file` with an `expected_version` that no longer matches returns `ChangedOnDisk`; the UI offers Overwrite or Reload.
- **No file watching.** The tree has a Refresh button; changes on disk are caught at save. `// ponytail:` add a watcher if users ask for live trees.
- **Tree:** dotfiles shown, `.git` hidden, `.gitignore` respected inside git repositories (git's own rule), folders first then names case-insensitively, one folder level loaded per expand, rows virtualized.
- **Separate chat surfaces.** `send_message` and `stop_reply` take a `ChatSurface` (`chat` or `workspace`), so a reply in the AI panel and one in Chat never cancel each other. The workspace conversation lives in memory, like Chat, until M5.
- **The AI panel shares the selected model with Chat** (the default model from M2).
- **The AI context is built in the frontend** from the live buffer, including unsaved edits, as one user message: attached file, then selection, then the question, each code part in a fence longer than any backtick run inside it. A short system message tells the model that attached content is data and asks for complete code in one fenced block.
- **A file chip is disabled above 100,000 characters** ("Select the part you need").
- **Apply target:** the file attached to the question (or the active tab if none), replacing the attached selection when there was one, otherwise the whole file. If the selected text no longer occurs exactly once, Apply says so instead of guessing.
- **The diff is a unified view** (`unifiedMergeView` from `@codemirror/merge`) over the centre pane: one editor instead of two, which fits beside the tree and the AI panel.
- **Languages load lazily** through `@codemirror/language-data` (each language is its own chunk; nothing loads until a file of that type opens).
- **Unsaved changes are never dropped silently:** closing a dirty tab, closing or switching the folder, and quitting the app all ask first (Task 10).
- **The Workspace screen stays mounted** once visited (hidden, not unmounted, when another screen is active), so tabs, buffers and undo history survive navigation.

- **D1, folder picker:** the plan uses `tauri-plugin-dialog` from Rust only (official Tauri plugin, built on `rfd`; no JavaScript permission). The alternative is the `rfd` crate directly, which avoids a Tauri plugin but leaves macOS main-thread handling to us. Default: the plugin.

### Task 2: Path checks and the secret-file filter

**Produces:**
- `workspace/mod.rs`: `WorkspaceError` (`Serialize, Deserialize, Type, Clone, Debug, PartialEq`, `#[serde(tag = "kind", rename_all = "camelCase")]`): `NoFolder`, `OutsideFolder`, `NotFound`, `NotText`, `TooLarge { bytes: u32 }`, `ChangedOnDisk`, `Io { message: String }`, `Storage { message: String }`.
- `workspace/paths.rs`:
  - `pub fn resolve(root: &Path, rel: &str) -> Result<PathBuf, WorkspaceError>`. `root` must already be canonical. In order: `rel` containing `:` or `\0` -> `OutsideFolder`; any component of `Path::new(rel)` other than `Normal` or `CurDir` (that is `ParentDir`, `RootDir`, `Prefix`) -> `OutsideFolder`; build the path by pushing each component onto `root` (never `join` the string); `std::fs::canonicalize` it (`NotFound` for `io::ErrorKind::NotFound`, else `Io`); a result that does not `starts_with(root)` -> `OutsideFolder`. `""` resolves to `root`.
  - `pub fn to_rel(root: &Path, abs: &Path) -> Option<String>`: `strip_prefix`, components joined with `/`.
- `workspace/secret_files.rs`: `pub fn is_secret(rel: &str) -> bool`, on the lowercase last component: starts with `.env`, ends with `.pem` or `.key`, starts with `id_rsa` or `id_ed25519`.
- `tests/common/mod.rs`: `TempDir` (unique folder under `std::env::temp_dir()` from process id and nanoseconds since the epoch; `path()`; `Drop` removes it) and `link_dir(link, target)`: on Windows `cmd /C mklink /J link target` (a junction needs no admin rights or Developer Mode), on Unix `std::os::unix::fs::symlink`.

### Task 3: Reading, writing and listing files

**Produces in `workspace/files.rs`:**
- `DirEntry { name: String, path: String, is_dir: bool }`, `LineEnding { Lf, Crlf }`, `FileContent { path, text, version: String, line_ending, has_bom: bool, is_secret: bool }`, `WriteFile { path, text, line_ending, has_bom, expected_version: Option<String> }` (all `Type`, camelCase; `WriteFile` is `Deserialize`). `pub const MAX_FILE_BYTES: u64 = 2 * 1024 * 1024`.
- `pub fn decode(bytes: &[u8]) -> Result<(String, LineEnding, bool), WorkspaceError>` and `pub fn encode(text: &str, le: LineEnding, bom: bool) -> Vec<u8>` (pure; `encode` first turns any `\r\n` into `\n`, so it never writes `\r\r\n`).
- `pub fn list_dir(root, rel) -> Result<Vec<DirEntry>, WorkspaceError>`: `resolve`, must be a folder (else `NotFound`); `ignore::WalkBuilder::new(abs).max_depth(Some(1)).hidden(false).filter_entry(|e| e.file_name() != ".git")`, skip the depth-0 entry, `path` from `to_rel`; folders first, then names case-insensitively. Symlinked entries are listed as files and are not followed (`resolve` refuses them later if they point outside).
- `pub fn read_file(root, rel) -> Result<FileContent, WorkspaceError>`: `resolve`; metadata size over `MAX_FILE_BYTES` -> `TooLarge { bytes }` (clamped to `u32::MAX`); read; `decode`; `version` = `"{mtime_nanos}-{len}"`; `is_secret(rel)`.
- `pub fn write_file(root, req) -> Result<String, WorkspaceError>`: `resolve` (the file must exist); if `expected_version` is `Some` and differs from the current version -> `ChangedOnDisk`; `std::fs::write` of `encode(...)`; return the new version.
- `workspace/mod.rs`: `pub fn is_git(root: &Path) -> bool` (`.git`, folder or file, in the root or any ancestor).

  while ($i -lt $ids.Count) { $ids += @($all | Where-Object ParentProcessId -eq $ids[$i] | ForEach-Object ProcessId); $i++ }
  $p = Get-Process -Id $ids -ErrorAction SilentlyContinue
  "{0:N0} MB private, {1:N0} MB working set, {2} processes" -f (($p | Measure-Object PrivateMemorySize64 -Sum).Sum / 1MB), (($p | Measure-Object WorkingSet64 -Sum).Sum / 1MB), $p.Count
