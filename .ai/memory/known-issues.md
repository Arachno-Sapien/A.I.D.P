# Known issues

Bugs, gotchas, and approaches that failed. Newest first. If you hit one of the "not yet seen" items, move it up with the date and what actually happened.

## Seen in this repo

- **2026-11-11 · A local model set up its own Playwright MCP instead of calling the browser tools.** Asked to "install the Playwright MCP properly & test it", qwen-3.8-27b ran `npm install @playwright/mcp`, wrote `.mcp.json` and an SDK client started with `--port 3001` (HTTP mode, so its stdio connect waits until the 120 s command timeout). Tool names say `mcp__browser__…`, not Playwright. `OUTSIDE_TOOLS_NOTE` now says the tools are already running and not to install or script a server; the app never reads `.mcp.json` from the folder (outside-tool rule 1).
- **2026-11-11 · The agent can't keep a server running.** A model command's job object kills everything it started when it ends, `Start-Process` and `start /B` included (`tools/command.rs`, by design: workspace rule 4). In a live Browser checks run the model spent all 25 steps starting `python -m http.server` and getting `ERR_CONNECTION_REFUSED`. `OUTSIDE_TOOLS_NOTE` now tells it to ask the user to run the server in the terminal. Letting the agent start long-lived servers needs a decision first.
- **2026-11-10 · A specta command takes at most 10 arguments, `State` and `AppHandle` included.** An 11th fails with `SpectaFn<_> is not satisfied` on the whole `collect_commands!`. `run_agent` hit it; it now takes `app: tauri::AppHandle` and gets the attachment store and the MCP hub with `app.state::<T>()`.
- **2026-11-10 · Python on Windows writes CRLF in text mode.** A patch script using `open(p).read()` / `open(p, 'w').write()` turned five LF files into CRLF (git warned "CRLF will be replaced by LF"). Open files with `newline=""` in patch scripts.

- **2026-11-10 · A store hook with no selector renders on every change.** `useWorkspaceStore()` in `App.tsx`, `WorkspaceScreen`, `EditorPane` and others re-rendered them on every cursor move, because the store holds the editor's `selection`; `useChatStore()` in `ConversationList` re-rendered it on every streamed chunk. Read state with `useShallow((s) => ({ ... }))` from `zustand/react/shallow` and take actions from `getState()` (they never change).
- **2026-11-10 · A new function in react-markdown's `components` is a new component type.** `Markdown.tsx` built `components` on every render, so React threw away and rebuilt every code block (and highlighted it again) on each streamed chunk; `memo` alone can't help then. `components` is in `useMemo` and the blocks get a never-changing `apply` that reads the latest `onApply` from a ref. Test: "a finished code block is not highlighted again as the reply grows".
- **2026-11-10 · Check after every `await` in a store action.** Two calls can both pass a check made before it: a double-click opened a file in two tabs (`openFile`), two quick saves sent the same `expectedVersion` and the second looked like a change on disk (`save`, now queued per file), Send twice posted twice (`send`). The text to save is still read at once when no save is ahead of it (`editorSync.test.ts` "an edit typed while saving stays unsaved").
- **2026-11-10 · Every wait in an adapter must race the cancel token,** the request itself too, not only the stream: `ollama_chat.rs` awaited `send()` bare, so Stop did nothing while Ollama loaded the model (test `stop_works_while_the_model_loads`).
- **2026-11-10 · Patch scripts through the Bash tool lose `\n` escapes.** A Python heredoc turned `"\\n"` into real line breaks inside a test's string (parse error, "no tests"). Put the script in a file with the Write tool, or use Edit.

- **2026-11-09 · `\\?\` and plain Windows paths can name different entries.** Plain paths drop trailing dots and spaces (`notes.` is `notes`, `sub\...` is `sub`); `\\?\` paths keep them. `to_trash` strips `\\?\` for the shell, so before the fix deleting a file named `...` (which the agent's `create_file` could make) would have sent its folder to the Recycle Bin; the test reproduced it. `check_components` now refuses such names on Windows; a second review pointed out that a link (or the opened folder's own path) can still bring one in after canonicalizing, so `files::shell_path` checks the whole plain path right where `to_trash` makes it. Any new code that turns a checked `\\?\` path into a plain one must go through `shell_path`. A junction made with `mklink /J` drops the dot from its target, so tests of this use `symlink_dir` (needs Developer Mode; the test skips without).

- **2026-11-09 · CodeMirror's panels are z-index 300.** With nothing containing them, the editor's count line (and the Ctrl+F search bar) painted over z-50 dialogs and menus. The editor container in `EditorPane.tsx` has `isolate`; keep it, and keep new overlays out of panels with a theme blur (`createPortal` to `document.body`, as `TreeMenu`, `ConfirmDialog` and the drag label do).
- **2026-11-09 · HTML drag-and-drop doesn't reach the page in Tauri on Windows.** The window takes drag events for files dropped from the OS (attachments). Dragging inside the app uses mouse events (`FileTree.tsx`); `document.elementFromPoint` finds the drop row, which jsdom lacks, so tests stub it.
- **2026-11-09 · The `trash` crate gets a plain path.** `resolve_entry` gives `\\?\C:\...`; `to_trash` passes `display_path` of it, because the Windows shell API it uses doesn't read `\\?\` paths (not tried without). Tests pass their own put-away function; only the ignored `to_trash_really_moves_a_file_to_the_trash` uses the real Recycle Bin.

- **2026-11-09 · `autoFocus` runs only when an element mounts.** A box that changes role in place (New file → New folder) keeps the old element, so it isn't focused and typing goes to whatever was clicked. Give it a `key` per role (`NewEntry.tsx`). Tests: focus the clicked button first, then check `document.activeElement`.

- **2026-11-09 · Keep `typescript` out of the main thread.** It is 3.5 MB minified. Only `diagnostics/typescriptWorker.ts` imports it at runtime; `typescriptSyntax.ts` takes `ts` as an argument and imports only its types. A runtime `import ts from "typescript"` anywhere else puts the compiler in the main bundle: check `dist/assets/index-*.js` stays near 1.08 MB after `npx vite build`. Use `getSyntacticDiagnostics` from a language service, not `transpileModule`, which throws on `.d.ts` files (no output).

- **2026-11-09 · CodeMirror's grammars flag valid code in many languages.** Measured on real files (decision 0022): TypeScript misreads `export { type X }`, `(p): p is T`, `declare module`, labeled tuples, `typeof import()`, `{/* */}` in JSX; JavaScript misreads import attributes and `export default class extends`; Python misreads bare `yield` and `1.`; HTML misreads template tags; CSS misreads Tailwind's `@apply`. Updating doesn't help (`@lezer/*` were at their latest). Don't add a language to `CHECKED` in `diagnostics/syntax.ts` without running its grammar over real valid files first.
- **2026-11-09 · Lint and partial parse trees.** `ensureSyntaxTree` returns null when its time budget runs out (it did under the full parallel Vitest run), and a cut-off tree can end in error nodes that aren't in the code. Lint re-runs only on edits unless `needsRefresh` says so. The syntax checker returns nothing for an unfinished tree and refreshes when `syntaxTree` changes. Also: deleting a problem's text removes the diagnostic by mapping with no `setDiagnosticsEffect`, so read `diagnosticCount(state)` rather than counting effects.

- **2026-11-09 · `timeout_kills_the_whole_tree` (`tests/tools.rs`) failed once in the full `cargo test`.** `marker.txt` existed 5 s after the 1 s timeout, so the timed-out `cmd` lived long enough to write it. Nothing had changed in Rust; it passed 3 of 3 runs alone and the next full run. Cause not found. If it fails again, check whether the timeout kill can miss the child under load (the job object in `tools/command.rs`) before calling it a slow-machine flake: a timed-out model command that keeps running breaks workspace rule 4.

- **2026-10-30 · Splitting model keys with colons.** Model identifiers can contain colons (e.g. `qwen2.5-coder:1.5b` or custom tag prefixes). Splitting on `:` blindly via `val.split(":")` breaks the model ID into multiple pieces. Split only on the first colon using `indexOf(":")` and `slice` (`parseModelKey`).
- **2026-10-30 · JSDOM lacks `window.matchMedia`.** JSDOM does not provide `window.matchMedia` by default. In tests exercising system theme media queries, assign `window.matchMedia = vi.fn().mockImplementation(...)` rather than calling `vi.spyOn(window, "matchMedia")` which throws on undefined.
- **2026-10-30 · Clippy derivable_impls on simple enum Defaults.** Writing manual `impl Default` for fieldless enums (`Theme`, `KeepAlive`) triggers `-D clippy::derivable-impls` under MSVC Rust. Use `#[derive(Default)]` and tag the default variant with `#[default]`.

When two agents work at once, one of them uses a git worktree (`git worktree add ../aidp-<task> -b <branch>`, junction `node_modules` to the main checkout) and merges when green.
- **2026-10-30 · Test temp folders collided.** `common::TempDir` named folders `aidp-test-{pid}-{nanos}` and used `create_dir_all`, so two parallel tests reading the same clock tick shared one folder and the first to finish deleted it. Symptoms looked random: `run_command` failing to start, `edit_waits_for_accept` never seeing its approval, a command result that was not `Exit code 0`. A `create_dir` probe hit collisions in most runs. Names now end in a per-process counter and `create_dir` fails loudly.
- **2026-10-30 · Windows ConPTY stdout pipe EOF requires dropping/closing master.** With ConPTY on Windows, `reader.read()` does not return EOF when the spawned child exits unless `ClosePseudoConsole` is called. In `tools/pty.rs`, a waiter thread monitors child exit with `try_wait()` and takes/drops `master`, which drops `PsuedoCon` and triggers `ClosePseudoConsole`, cleanly unblocking the reader thread to emit `Exit`. ConPTY also sends `\x1b[6n` (DSR cursor position query) on start.
- **2026-10-30 · The `ignore` walker yields file links even with `follow_links(false)`.** It only stops descending into linked folders. Reading `entry.path()` follows a file link, so M4's `search` returned `.env` through a link named `notes.txt`, and a file outside the folder. Check `entry.file_type().is_some_and(|ft| ft.is_file())` before reading; test with `common::link_file` (works on this machine, Developer Mode).
- **2026-10-30 · A child's exit is not the end of its output.** `start /b x` or `x &` exits the shell while `x` keeps the stdout pipe open, so awaiting the reader after `wait()` can block for good. In `tools/command.rs` the reading is raced against Stop and the timeout. On Windows a process whose parent already exited is outside `taskkill /T`; since M6 a job object ends it (`Job` in `tools/command.rs`, test `stop_ends_a_detached_process`).
- **2026-10-30 · `value["key"] = ...` panics on a non-object `serde_json::Value`,** and release builds use `panic = "abort"`, so a malformed stream from a custom base URL would close the app. Write through `as_object_mut()`.
- **2026-10-30 · Windows CreateProcess command length (os error 206).** Passing more than 32,767 characters directly on the command line in Windows `cmd.exe` fails with "The filename or extension is too long (os error 206)". Commands in tests or scripts generating large outputs should use a loop (e.g. `for /L %i in (1,1,400) do @echo ...`) or stream rather than embedding massive arguments on the command line.
- **2026-10-30 · Clippy `await-holding-lock` in async tests.** Holding a `std::sync::MutexGuard` (e.g. on captured event channels) across an `.await` point triggers `-D clippy::await-holding-lock`. Always clone or scope the mutex lock before calling `.await`.
- **2026-10-30 · A CodeMirror view keeps its own state.** `EditorView` replaces its `EditorState` on every keystroke; the state object you created is never updated. M3 Tasks 7 to 11 passed 108 tests while typed edits never reached `buffers`, so Save wrote the original text. Every state now writes itself back through the `onUpdate` listener in `cm.ts`, and `editorSync.test.ts` types into a real view in jsdom. Keep a test like it for any new editor feature; tests that set `buffers` by hand cannot catch this.
- **2026-10-30 · Release CSP and CodeMirror styling.** CodeMirror 6 injects syntax highlighting and editor styling via inline `<style>` tags generated by JavaScript. On Windows release builds, styles render cleanly without CSP violations when `style-src` permits inline style tags; script-src remains strictly `'self'`.
- **2026-10-30 · CRLF normalisation in CodeMirror 6.** CodeMirror normalises all document line breaks to `\n` in memory. If a Windows file with CRLF line endings is saved directly, every line break changes and git shows a full-file diff. Rust backend records `LineEnding` on `read_file` and restores CRLF during `write_file` encoding (`encode_line_endings`), preserving exact repo conventions.
- **2026-10-30 · Verbatim-path `/` trap on Windows.** Windows canonical paths use verbatim prefixes (`\\?\C:\...`). Appending forward slashes (e.g. `\\?\C:\repo/subfolder`) breaks Windows win32 API calls (`FindFirstFileW`). Path resolution in `workspace::paths::resolve` converts components using `PathBuf::push` with native separators.
- **2026-10-30 · TanStack React Virtual in JSDOM.** JSDOM returns `0` for `clientWidth` and `clientHeight`. `@tanstack/react-virtual`'s default `observeElementRect` overrides `initialRect` with `{ width: 0, height: 0 }`, causing 0 virtualized rows to render in tests. In `FileTree.tsx`, `observeElementRect` falls back to `instance.options.initialRect` when measured client dimensions are 0.

- **2026-10-30 · Links in Windows tests.** Folder links: `mklink /J` (a junction) needs no admin rights. File symlinks (`std::os::windows::fs::symlink_file`) need admin or Developer Mode, so `tests/common::link_file` returns false and the test skips where they are refused. `FileType::is_symlink()` is true for junctions too, so `list_dir` lists them as files.
- **2026-10-30 · Display paths on Windows.** `canonicalize` gives `\\?\C:\...` and, for network folders, `\\?\UNC\server\share\...`. Use `workspace::display_path`, which turns the second into `\\server\share\...`; stripping only `\\?\` leaves `UNC\...`, which does not reopen.
- **2026-10-30 · Vitest without global test environment does not auto-cleanup JSDOM.** In `vite.config.ts`, `globals` is false, so `@testing-library/react` does not automatically register an afterEach cleanup hook. Each component test file (`*.test.tsx`) must import `cleanup` and register `afterEach(() => { cleanup(); })`, otherwise DOM nodes from earlier tests remain in `document.body` and cause `TestingLibraryElementError: Found multiple elements` in later tests.
- **2026-10-30 · JSDOM lacks `element.scrollIntoView`.** `window` and DOM elements in JSDOM do not provide `scrollIntoView`. Call defensively using optional chaining: `ref.current?.scrollIntoView?.({ behavior: "smooth" })`.
- **2026-10-30 · rusqlite bundled feature on Windows.** Enabled `features = ["bundled"]` in `Cargo.toml` so Windows MSVC builds compile embedded SQLite C source directly and do not require external SQLite DLLs or system libraries.
- **2026-10-30 · keyring 4.2 in unit tests.** `keyring::Entry` operates directly against the host OS store. To keep tests deterministic and prevent pollution of the developer's Windows Credential Manager (or failure on headless CI runners), keychain calls are abstracted behind a `SecretStore` trait with `MemoryStore` for tests and `Keychain` for production.
- **2026-10-30 · reqwest `.header(name, &str)` does not mark a key header as sensitive.** Build a `HeaderValue`, call `set_sensitive(true)`, and map a `from_str` failure to `InvalidKey` (see `key_header` in `gateway/anthropic.rs`). The review caught the Anthropic adapter passing the raw string.
- **2026-10-30 · Pasted keys carry whitespace.** A key copied with a trailing newline makes `HeaderValue::from_str` fail, which shows up as `InvalidKey`. `connections.rs` trims the key before testing and saving it; keep that for any new way in.
- **2026-10-29 · tauri-specta rejects 64-bit integers.** `u64` and `i64` (BigInt) in exported types fail the TypeScript export, because JavaScript numbers lose precision. Use `u32` (as `ProviderError::RateLimited.retry_after_secs` does) or a string.
- **2026-10-29 · Some providers report failures inside a 200 stream.** OpenRouter sends an `{"error": {...}}` object in the SSE data after streaming has started. `gateway/openai_compat.rs` turns it into `ProviderError::Provider`. Check for the same in any new adapter.
- **2026-10-29 · Closing a terminal tab does not stop `npm run tauri dev`.** The tauri CLI, the Vite server (port 1420) and the debug `aidp.exe` kept running, and the watcher restarted the app on every `src-tauri` edit. `cargo test` then failed with `failed to remove file ...\target\debug\aidp.exe, Access is denied (os error 5)`. - **2026-10-29 · Claude Code's Bash sandbox hides writes outside the project.** A file written by the Bash tool to `%APPDATA%` (or anywhere outside the repo) looked fine to later Bash commands but never reached the real disk, so the app reported `config.local.json` as missing. - **2026-10-29 · reqwest default TLS and Windows MSVC.** In reqwest 0.13, default TLS uses `rustls` backed by `aws-lc-rs`, which requires CMake and NASM on Windows. ## From docs, not yet seen here (check when you get there)

- **Streaming parsers:** network chunks don't line up with lines. Buffer bytes and split on newlines before parsing. OpenAI-compatible APIs send SSE `data:` lines ending with `data: [DONE]`; Anthropic sends SSE with named `event:` lines; Ollama `/api/chat` streams NDJSON (one JSON object per line).
