# Known issues

Bugs, gotchas, and approaches that failed. Newest first. If you hit one of the "not yet seen" items, move it up with the date and what actually happened.

## Seen in this repo

- **2026-10-30 · Windows ConPTY stdout pipe EOF requires dropping/closing master.** With ConPTY on Windows, `reader.read()` does not return EOF when the spawned child exits unless `ClosePseudoConsole` is called. In `tools/pty.rs`, a waiter thread monitors child exit with `try_wait()` and takes/drops `master`, which drops `PsuedoCon` and triggers `ClosePseudoConsole`, cleanly unblocking the reader thread to emit `Exit`. ConPTY also sends `\x1b[6n` (DSR cursor position query) on start.
- **2026-10-30 · The `ignore` walker yields file links even with `follow_links(false)`.** It only stops descending into linked folders. Reading `entry.path()` follows a file link, so M4's `search` returned `.env` through a link named `notes.txt`, and a file outside the folder. Check `entry.file_type().is_some_and(|ft| ft.is_file())` before reading; test with `common::link_file` (works on this machine, Developer Mode).
- **2026-10-30 · A child's exit is not the end of its output.** `start /b x` or `x &` exits the shell while `x` keeps the stdout pipe open, so awaiting the reader after `wait()` can block for good. In `tools/command.rs` the reading is raced against Stop and the timeout. Ceiling: on Windows a process whose parent already exited is outside `taskkill /T` and keeps running; a job object would catch it.
- **2026-10-30 · `value["key"] = ...` panics on a non-object `serde_json::Value`,** and release builds use `panic = "abort"`, so a malformed stream from a custom base URL would close the app. Write through `as_object_mut()`.
- **2026-10-30 · Windows CreateProcess command length (os error 206).** Passing more than 32,767 characters directly on the command line in Windows `cmd.exe` fails with "The filename or extension is too long (os error 206)". Commands in tests or scripts generating large outputs should use a loop (e.g. `for /L %i in (1,1,400) do @echo ...`) or stream rather than embedding massive arguments on the command line.
- **2026-10-30 · Clippy `await-holding-lock` in async tests.** Holding a `std::sync::MutexGuard` (e.g. on captured event channels) across an `.await` point triggers `-D clippy::await-holding-lock`. Always clone or scope the mutex lock before calling `.await`.
- **2026-10-30 · A CodeMirror view keeps its own state.** `EditorView` replaces its `EditorState` on every keystroke; the state object you created is never updated. M3 Tasks 7 to 11 passed 108 tests while typed edits never reached `buffers`, so Save wrote the original text. Every state now writes itself back through the `onUpdate` listener in `cm.ts`, and `editorSync.test.ts` types into a real view in jsdom. Keep a test like it for any new editor feature; tests that set `buffers` by hand cannot catch this.
- **2026-10-30 · Release CSP and CodeMirror styling.** CodeMirror 6 injects syntax highlighting and editor styling via inline `<style>` tags generated by JavaScript. On Windows release builds, styles render cleanly without CSP violations when `style-src` permits inline style tags; script-src remains strictly `'self'`.
- **2026-10-30 · CRLF normalisation in CodeMirror 6.** CodeMirror normalises all document line breaks to `\n` in memory. If a Windows file with CRLF line endings is saved directly, every line break changes and git shows a full-file diff. Rust backend records `LineEnding` on `read_file` and restores CRLF during `write_file` encoding (`encode_line_endings`), preserving exact repo conventions.
- **2026-10-30 · Verbatim-path `/` trap on Windows.** Windows canonical paths use verbatim prefixes (`\\?\C:\...`). Appending forward slashes (e.g. `\\?\C:\repo/subfolder`) breaks Windows win32 API calls (`FindFirstFileW`). Path resolution in `workspace::paths::resolve` converts components using `PathBuf::push` with native separators.
- **2026-10-30 · TanStack React Virtual in JSDOM.** JSDOM returns `0` for `clientWidth` and `clientHeight`. `@tanstack/react-virtual`'s default `observeElementRect` overrides `initialRect` with `{ width: 0, height: 0 }`, causing 0 virtualized rows to render in tests. In `FileTree.tsx`, `observeElementRect` falls back to `instance.options.initialRect` when measured client dimensions are 0.

- **2026-10-30 · Links in Windows tests.** Folder links: `mklink /J` (a junction) needs no admin rights. File symlinks (`std::os::windows::fs::symlink_file`) need admin or Developer Mode, so `tests/common::link_file` returns false and the test skips where they are refused. `FileType::is_symlink()` is true for junctions too, so `list_dir` lists them as files.
- **2026-10-30 · Display paths on Windows.** `canonicalize` gives `\\?\C:\...` and, for network folders, `\\?\UNC\server\share\...`. Use `workspace::display_path`, which turns the second into `\\server\share\...`; stripping only `\\?\` leaves `UNC\...`, which does not reopen.
- **2026-10-30 · Vitest without global test environment does not auto-cleanup JSDOM.** In `vite.config.ts`, `globals` is false, so `@testing-library/react` does not automatically register an afterEach cleanup hook. Each component test file (`*.test.tsx`) must import `cleanup` and register `afterEach(() => { cleanup(); })`, otherwise DOM nodes from earlier tests remain in `document.body` and cause `TestingLibraryElementError: Found multiple elements` in later tests.
- **2026-10-30 · JSDOM lacks `element.scrollIntoView`.** `window` and DOM elements in JSDOM do not provide `scrollIntoView`. Call defensively using optional chaining: `ref.current?.scrollIntoView?.({ behavior: "smooth" })`.
- **2026-10-30 · rusqlite bundled feature on Windows.** Enabled `features = ["bundled"]` in `Cargo.toml` so Windows MSVC builds compile embedded SQLite C source directly and do not require external SQLite DLLs or system libraries.
- **2026-10-30 · keyring 4.2 in unit tests.** `keyring::Entry` operates directly against the host OS store. To keep tests deterministic and prevent pollution of the developer's Windows Credential Manager (or failure on headless CI runners), keychain calls are abstracted behind a `SecretStore` trait with `MemoryStore` for tests and `Keychain` for production.
- **2026-10-30 · reqwest `.header(name, &str)` does not mark a key header as sensitive.** Build a `HeaderValue`, call `set_sensitive(true)`, and map a `from_str` failure to `InvalidKey` (see `key_header` in `gateway/anthropic.rs`). The review caught the Anthropic adapter passing the raw string.
- **2026-10-30 · Pasted keys carry whitespace.** A key copied with a trailing newline makes `HeaderValue::from_str` fail, which shows up as `InvalidKey`. `connections.rs` trims the key before testing and saving it; keep that for any new way in.
- **2026-10-29 · tauri-specta rejects 64-bit integers.** `u64` and `i64` (BigInt) in exported types fail the TypeScript export, because JavaScript numbers lose precision. Use `u32` (as `ProviderError::RateLimited.retry_after_secs` does) or a string.
- **2026-10-29 · Some providers report failures inside a 200 stream.** OpenRouter sends an `{"error": {...}}` object in the SSE data after streaming has started. `gateway/openai_compat.rs` turns it into `ProviderError::Provider`. Check for the same in any new adapter.
- **2026-10-29 · Closing a terminal tab does not stop `npm run tauri dev`.** The tauri CLI, the Vite server (port 1420) and the debug `aidp.exe` kept running, and the watcher restarted the app on every `src-tauri` edit. `cargo test` then failed with `failed to remove file ...\target\debug\aidp.exe, Access is denied (os error 5)`. Press Ctrl+C in the tab before closing it. To clean up afterwards, find the `tauri.js dev`, `vite.js` and `target\debug\aidp.exe` processes and `Stop-Process` those ids. Never stop other `node.exe` processes, which belong to the human's other tools.
- **2026-10-29 · Claude Code's Bash sandbox hides writes outside the project.** A file written by the Bash tool to `%APPDATA%` (or anywhere outside the repo) looked fine to later Bash commands but never reached the real disk, so the app reported `config.local.json` as missing. To create files the app or the human must see outside the repo, use the human's terminal (run_in_terminal) or ask the human. Check with `Get-ChildItem` in that terminal, not with Bash.
- **2026-10-29 · reqwest default TLS and Windows MSVC.** In reqwest 0.13, default TLS uses `rustls` backed by `aws-lc-rs`, which requires CMake and NASM on Windows. Without them `cargo build` / `cargo test` fails. Fix: set `default-features = false` and enable `features = ["native-tls", "charset", "http2", "system-proxy", "json", "stream"]` (decision record 0006).
- **2026-10-29 · Windows MSVC `cargo test` and ComCtl32 v6 (STATUS_ENTRYPOINT_NOT_FOUND 0xc0000139).** When `aidp_lib` unit test binary is built by `cargo test --lib`, it doesn't get the Windows Application Manifest embedded by default. Because Tauri/Wry/Muda pulls in `TaskDialogIndirect` from `comctl32.dll`, Windows loads ComCtl32 v5.82 without a manifest and fails process initialization with `0xc0000139`. Fix: pass `/MANIFESTDEPENDENCY` for Common-Controls v6 via `cargo:rustc-link-arg` in `src-tauri/build.rs`, only when `CARGO_CFG_TARGET_ENV` is `msvc`. Unguarded, it breaks macOS/Linux builds, because their linkers read the flag as a file name.
- **2026-10-29 · Windows long paths.** `git clone` of some repos fails with "Filename too long" (seen with vercel-labs/agent-skills). The skills CLI still installed fine. Fix if needed: `git config --global core.longpaths true` (ask the human; it's a machine-wide setting).
- **2026-10-29 · Ollama "installed" ≠ "running".** `ollama --version` prints "could not connect to a running Ollama instance" when the server is off. Detection: try `GET 127.0.0.1:11434/api/version` first; only if that fails, look for the binary and offer Start.
- **2026-10-29 · Claude Code on the dev machine** has hooks (ECC GateGuard) that ask for a short fact statement before the first Bash/Write. That's the human's local setup, not a project bug: answer it and retry the same call.

## From docs, not yet seen here (check when you get there)

- **Streaming parsers:** network chunks don't line up with lines. Buffer bytes and split on newlines before parsing. OpenAI-compatible APIs send SSE `data:` lines ending with `data: [DONE]`; Anthropic sends SSE with named `event:` lines; Ollama `/api/chat` streams NDJSON (one JSON object per line). The OpenAI-compatible and Anthropic adapters share `gateway/sse.rs` and `read_sse` in `gateway/http.rs` (tested with split UTF-8 and `event:` lines); Ollama (M5) still needs an NDJSON reader.
- **tauri-specta and specta** versions must match. If they're still pre-release on crates.io, pin exact versions (`=x.y.z-rc.n`) for both.
- **Ollama on Windows** usually runs as a tray app that starts the server itself. Spawn `ollama serve` only when `/api/version` fails and the binary exists.
