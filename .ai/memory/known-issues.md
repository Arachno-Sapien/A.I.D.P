# Known issues

Bugs, gotchas, and approaches that failed. Newest first. If you hit one of the "not yet seen" items, move it up with the date and what actually happened.

## Seen in this repo

- **2026-10-29 · tauri-specta rejects 64-bit integers.** `u64` and `i64` (BigInt) in exported types fail the TypeScript export, because JavaScript numbers lose precision. Use `u32` (as `ProviderError::RateLimited.retry_after_secs` does) or a string.
- **2026-10-29 · Some providers report failures inside a 200 stream.** OpenRouter sends an `{"error": {...}}` object in the SSE data after streaming has started. `gateway/openai_compat.rs` turns it into `ProviderError::Provider`. Check for the same in any new adapter.
- **2026-10-29 · Closing a terminal tab does not stop `npm run tauri dev`.** The tauri CLI, the Vite server (port 1420) and the debug `aidp.exe` kept running, and the watcher restarted the app on every `src-tauri` edit. `cargo test` then failed with `failed to remove file ...\target\debug\aidp.exe, Access is denied (os error 5)`. Press Ctrl+C in the tab before closing it. To clean up afterwards, find the `tauri.js dev`, `vite.js` and `target\debug\aidp.exe` processes and `Stop-Process` those ids. Never stop other `node.exe` processes, which belong to the human's other tools.
- **2026-10-29 · Claude Code's Bash sandbox hides writes outside the project.** A file written by the Bash tool to `%APPDATA%` (or anywhere outside the repo) looked fine to later Bash commands but never reached the real disk, so the app reported `config.local.json` as missing. To create files the app or the human must see outside the repo, use the human's terminal (run_in_terminal) or ask the human. Check with `Get-ChildItem` in that terminal, not with Bash.
- **2026-10-29 · reqwest default TLS and Windows MSVC.** In reqwest 0.13, default TLS uses `rustls` backed by `aws-lc-rs`, which requires CMake and NASM on Windows. Without them `cargo build` / `cargo test` fails. Fix: set `default-features = false` and enable `features = ["native-tls", "charset", "http2", "system-proxy", "json", "stream"]` (decision record 0006).
- **2026-10-29 · Windows MSVC `cargo test` and ComCtl32 v6 (STATUS_ENTRYPOINT_NOT_FOUND 0xc0000139).** When `aidp_lib` unit test binary is built by `cargo test --lib`, it doesn't get the Windows Application Manifest embedded by default. Because Tauri/Wry/Muda pulls in `TaskDialogIndirect` from `comctl32.dll`, Windows loads ComCtl32 v5.82 without a manifest and fails process initialization with `0xc0000139`. Fix: pass `/MANIFESTDEPENDENCY` for Common-Controls v6 via `cargo:rustc-link-arg` in `src-tauri/build.rs`, only when `CARGO_CFG_TARGET_ENV` is `msvc`. Unguarded, it breaks macOS/Linux builds, because their linkers read the flag as a file name.
- **2026-10-29 · Windows long paths.** `git clone` of some repos fails with "Filename too long" (seen with vercel-labs/agent-skills). The skills CLI still installed fine. Fix if needed: `git config --global core.longpaths true` (ask the human; it's a machine-wide setting).
- **2026-10-29 · Ollama "installed" ≠ "running".** `ollama --version` prints "could not connect to a running Ollama instance" when the server is off. Detection: try `GET 127.0.0.1:11434/api/version` first; only if that fails, look for the binary and offer Start.
- **2026-10-29 · Claude Code on the dev machine** has hooks (ECC GateGuard) that ask for a short fact statement before the first Bash/Write. That's the human's local setup, not a project bug: answer it and retry the same call.

## From docs, not yet seen here (check when you get there)

- **keyring 3.x has no default platform features.** Without them it silently uses an in-memory mock store and keys disappear on restart. Enable `windows-native` (plus `apple-native` / a Linux Secret Service feature when those ports start). Check that a saved key shows up in Windows Credential Manager.
- **rusqlite:** enable the `bundled` feature so Windows builds don't need a system SQLite.
- **Streaming parsers:** network chunks don't line up with lines. Buffer bytes and split on newlines before parsing. OpenAI-compatible APIs send SSE `data:` lines ending with `data: [DONE]`; Anthropic sends SSE with named `event:` lines; Ollama `/api/chat` streams NDJSON (one JSON object per line). The OpenAI-compatible parser is done (`gateway/sse.rs`, tested with split UTF-8); Anthropic (M2) and Ollama (M5) still need theirs.
- **tauri-specta and specta** versions must match. If they're still pre-release on crates.io, pin exact versions (`=x.y.z-rc.n`) for both.
- **Ollama on Windows** usually runs as a tray app that starts the server itself. Spawn `ollama serve` only when `/api/version` fails and the binary exists.
